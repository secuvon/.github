# Contributing to Secuvon

Secuvon's code repositories are private, so we do not accept code
contributions from outside the team at the moment. If we open-source a
component, this page will explain how to contribute to it.

## How you can help today

| You want to | Do this |
| --- | --- |
| Report a security vulnerability | Email [security@secuvon.ai](mailto:security@secuvon.ai). See our [security policy](SECURITY.md) |
| Report a bug or give product feedback | Use **Send feedback** inside the app, or email [support@secuvon.ai](mailto:support@secuvon.ai) |
| Suggest a partnership, talk, article or case study | Email [hello@secuvon.ai](mailto:hello@secuvon.ai) |
| Report behaviour that breaks our Code of Conduct | Email [conduct@secuvon.ai](mailto:conduct@secuvon.ai) |

## Code of Conduct

Everyone who takes part in Secuvon's public spaces is expected to follow our
[Code of Conduct](CODE_OF_CONDUCT.md).

Secuvon is operated by NexPhase Technology Limited, Ireland.
